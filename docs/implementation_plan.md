# JSONOTE 프리미엄 UX/UI 및 레이아웃 대전환 계획

사용자께서 폰트 변경 위치를 찾기 어려워하셨고, 전반적인 UX/UI와 파일 형식에 대한 재검토를 요청하셨습니다. 이에 따라 앱을 더욱 '프리미엄'하고 직관적으로 개편합니다.

## User Review Required

- **폰트 스위처 위치**: 이제 좌측 하단에 숨겨두지 않고, 사이드바 상단 혹은 에디터 우측 상단에 '디자인 설정' 아이콘을 배치하여 즉시 접근 가능하게 하려 합니다. 어느 쪽이 더 편하실까요?
- **파일 형식**: 현재 `.json` 확장자를 유지하되, 내부 구조에 `version` 정보를 추가하여 향후 기능 확장에 대비하려 합니다. 혹시 범용성을 위해 `.md` (마크다운) 확장자로 변경하고 내부에 JSON 데이터를 담는 방식을 선호하시나요?

## Proposed Changes

### 1. UX/UI & Layout 프리미엄 고도화

#### [MODIFY] [globals.css](file:///d:/jsonote/src/app/globals.css)
- **Glassmorphism 심화**: 사이드바와 헤더에 더 깊은 블러 효과와 미세한 보더 글로우(Border Glow) 적용.
- **레이아웃 재구조화**: 사이드바 폭을 조금 더 넓히고, 아이템 간의 여백(Spacing)을 늘려 시각적 피로도 감소.
- **애니메이션 추가**: 리스트 항목 호버 시의 미세한 스케일 업, 탭 전환 시의 슬라이드 효과 보강.

#### [MODIFY] [page.tsx](file:///d:/jsonote/src/app/page.tsx)
- **사이드바 하단 개편**: 복잡한 버튼 나열을 '환경 설정'과 '외관 설정'으로 그룹화.
- **퀵 세팅 메뉴**: 상단 헤더에 다크모드, 폰트(고딕/명조), 나이트 모드를 한 번에 조절할 수 있는 드롭다운 혹은 버튼 세트 배치.

### 2. 폰트 스위칭 가시성 개선
- **아이콘 + 텍스트**: 단순히 '가'라고 적힌 작은 버튼이 아닌, "Gothic / Myeongjo" 또는 "고딕 / 명조"가 명시된 토글 스위치 형태의 UI 도입.

### 3. 파일 형식 및 구조 최적화 (Data Sovereignty)

#### [MODIFY] [storage.ts](file:///d:/jsonote/src/lib/storage.ts) & [note.ts](file:///d:/jsonote/src/types/note.ts)
- **스키마 버전 관리**: 모든 JSON 파일 상단에 `version: "1.0"` 추가.
- **데이터 정규화**: `updatedAt` 등 타임스탬프 형식을 밀리초 단위까지 정밀하게 관리하여 동기화 충돌 방지 보강.
